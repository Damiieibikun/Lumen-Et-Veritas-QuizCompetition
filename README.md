# 🎓 Lumen Et Veratis | Quiz Portal

A web-based quiz portal built for educational institutions to register candidates to take standardized online assessments. This interactive platform allows institutions to register candidates who will take a quiz, and view their results—all within a user-friendly interface.

## 🚀 Features

- 🔐 Candidate registration and validation
- 📋 Randomized quiz generation (10 MCQs)
- ⏱ Countdown timer with automatic submission
- 📊 Score display and ranking of top performers
- 🏆 Winner showcase modal for top 3 scorers
- 🎨 Styled with Bootstrap 5 and Tailwind CSS

## 💡 Usage (Institution)

1. Register your institution.
2. Enter your full name, email address and phone number.
3. Provide selected candidate's details.


## 💡 Usage (Candidate)

1. Select your institution.
2. Enter your full name and verify.
3. Provide contact details for final verification.
4. Read quiz instructions and begin.
5. The quiz is timed (2 minutes) and consists of 10 multiple choice questions.
6. View results and see top scorers post submission.

## 🛠 Tech Stack

- HTML5
- JavaScript (Vanilla)
- Bootstrap 5
- Tailwind CSS

- General Knowledge
- Verbal & Quantitative Reasoning
